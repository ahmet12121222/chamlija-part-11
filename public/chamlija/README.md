# Chamlija photography

The homepage uses only the real Chamlija photos supplied for the site. Keep the photo set centralized
in the config file and avoid any stock, generated, or placeholder imagery.

Current local source layout:

```
public/chamlija/
  hero/            hero-01.jpeg
  about/           about-01.jpeg, about-02.jpeg
  categories/      picnic-area-01.jpeg, tent-event-01.jpeg, activities-01.jpeg, photo-shoot-01.jpeg
  gallery/         gallery-01.jpeg ... gallery-08.jpeg
  final-cta.jpeg
```

All homepage image mappings are managed in `lib/media/chamlija-images.ts`.
